# 📸 首页照片拼贴使用说明（云存储版）

## 🌥️ 照片上传到云存储

### 📐 照片准备要求
- **推荐尺寸：** 400×300px 或 600×450px
- **宽高比：** 4:3（横向照片）
- **文件大小：** 建议每张不超过500KB
- **文件格式：** JPG 或 PNG

### 📁 文件命名
将准备好的照片按以下命名：
- `photo1.jpg` - 照片1（左上角，向左倾斜-12度）
- `photo2.jpg` - 照片2（右上角，向右倾斜8度）
- `photo3.jpg` - 照片3（左下角，轻微左倾-6度）
- `photo4.jpg` - 照片4（右下角，向右倾斜10度）

### ☁️ 上传到云存储

#### 方法一：通过微信开发者工具上传
1. 打开微信开发者工具
2. 点击左侧导航栏的"云开发"图标
3. 选择"云存储"标签页
4. 找到或创建 `photos/` 文件夹
5. 点击"上传文件"按钮
6. 依次上传 4 张照片到 `photos/` 文件夹下

#### 方法二：通过云开发控制台上传
1. 打开浏览器，访问：https://console.cloud.tencent.com/tcb
2. 选择你的环境
3. 点击左侧"云存储"
4. 找到或创建 `photos/` 文件夹
5. 上传 4 张照片

### 🔗 获取云存储路径（可选）

如果你的云环境ID不同，需要修改 `pages/index/index.js` 中的路径：

1. 上传照片后，在云存储中点击照片
2. 复制"File ID"（云文件ID）
3. 修改 `index.js` 中的 `photos` 数组：

```javascript
photos: [
  'cloud://你的环境ID.xxx/photos/photo1.jpg',
  'cloud://你的环境ID.xxx/photos/photo2.jpg',
  'cloud://你的环境ID.xxx/photos/photo3.jpg',
  'cloud://你的环境ID.xxx/photos/photo4.jpg'
]
```

## 🔄 如何替换照片

### 简单方法（推荐）：
1. 准备4张新照片（按要求命名）
2. 打开微信开发者工具 → 云开发 → 云存储
3. 找到 `photos/` 文件夹
4. 删除旧照片，上传新照片（保持文件名一致）
5. 刷新小程序即可看到新照片

### 完整方法：
如果修改了文件名或路径，需要同步修改 `pages/index/index.js` 中的 `photos` 数组。

1. **便于管理**：通过云开发控制台随时上传/替换照片

## 💡 常见问题

### Q1: 照片不显示怎么办？
检查以下几点：
1. ✅ 照片是否成功上传到云存储的 `photos/` 文件夹
2. ✅ 文件名是否正确（photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg）
3. ✅ 云环境ID是否正确
4. ✅ 小程序是否有云开发权限

### Q2: 只想用3张照片可以吗？
可以！修改 `index.wxml`，删除或注释掉 photo-4：
```xml
<!-- <view class="photo-frame photo-4">
  <image class="photo-img" src="{{photos[3]}}" mode="aspectFill"></image>
</view> -->
```

### Q3: 如何调整照片位置和角度？
在 `index.wxss` 中修改对应照片的样式：
- `top/bottom/left/right` - 调整位置
- `rotate()` - 调整倾斜角度
- `width/height` - 调整照片大小

### Q4: 照片加载很慢？
- 确保照片文件大小不超过500KB
- 可以使用在线工具压缩照片（如TinyPNG）
- 微信云存储有CDN加速，通常很快
